# 미니 배달 주문 서비스입니다.

사장님은 **메뉴를 올리고**, 손님은 **주문하고 결제**하고,
사장님이 그 주문을 받아 **처리하는** 작은 배달 주문 서비스의
백엔드 API를 직접 만들어봅니다.

👤 회원·로그인 → 🍜 메뉴 → 🧾 주문 → 💳 결제 → ✅ 주문 처리

<aside>
📌

**이 서비스의 전제**

- **가게 = 사장님(OWNER) 한 명**입니다. 가게를 따로 만들지 않고, 사장님이 곧 가게라고 생각합니다.
- **배달 라이더는 없습니다.** 배달 완료 처리까지 사장님이 합니다.
- **결제는 실제 결제사(PG)와 연동하지 않습니다.** 결제 내역만 DB에 저장합니다.
- **주문 1건 = 메뉴 1개 + 수량**입니다. 여러 메뉴를 한 번에 담는 건 도전 기능입니다.
- 화면이 없으므로 **Postman 같은 API 테스트 도구**로 확인합니다.
</aside>

프로젝트 상세 요구사항은 [docs/requirements.md](docs/requirements.md) 에 있습니다.
